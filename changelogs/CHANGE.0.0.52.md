# Changelog

## [0.0.52] - 2026-10-15

## Changes

- 成功压缩卡片新增「尝试其他模型」：复用宿主会话模型目录选择模型与思考等级，在临时会话中以该模型重放同一次压缩，不修改原会话。
- 重压缩成功或失败都落盘为压缩会话记录，标题带「重压缩 provider/model」，显示在子智能体列表中。
- 压缩会话记录尾部追加一条模型文本，说明压缩所用模型与思考等级、原始消息与压缩产物字符数（k/w/M 单位，与卡片一致），普通压缩与重压缩均有。
- 点击「尝试其他模型」选定模型后弹出全局提示：压缩开始，完成后会添加至“子智能体”。
- 内部注册 `/om-recompress` 命令作为卡片到服务端的通道，完成记录形如“重压缩完成 provider/model(等级)，原始消息 → 产物，耗时”，卡片上的结果行超长可滚动。重压缩与压缩日志中的“原始消息”字符数与卡片同一口径。
- 进度提醒首句改为「在本会话中，你应当持续输出文本，…」，明确是本会话对 agent 的要求。
- 不再注入完整消息定义的 system-reminder（`plugin:dsh-plugin-om:definition`）；定义恢复到 `<history>` 块顶注释与 `recall`、`recall-semantic` 工具描述，压缩提示词保留。
- agent-workflow 技能：PR 合并后立即在主工作区 `git pull`，清理步骤不再包含拉取。
